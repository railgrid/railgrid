# Model catalog

Agents and App Studio share this catalog for standard input/output token price
estimates. Both portals' JSON assets are generated by
`make generate-model-catalog`; do not edit those copies.

`recommended` identifies current choices independently of historical pricing
coverage. New recommendations must also appear in the endpoint's discovered
model list; they do not change saved connections or guarantee account access.
Only exact IDs, provider-prefixed IDs, and dated snapshots inherit catalog data.
Other variants must not silently inherit an older model's price.

## Pricing confidence

The current OpenAI and Anthropic recommendation entries were checked on
2026-10-31 against:

- https://developers.openai.com/api/docs/models
- https://developers.openai.com/api/docs/pricing
- https://platform.claude.com/docs/en/models/overview
- https://platform.claude.com/docs/en/about-claude/pricing

Their `pricingCheckedAt` and `pricingSource` record this snapshot. Older entries
retain historical rates and have not been reverified in this update. Refresh
recommendations and prices together, review official sources, regenerate the
portal data, and run modelcatalog and both providers' model tests.

These are standard, uncached, short-context USD rates, not invoice attribution.
The current estimator does not account for cache reads or writes, service tiers,
batch discounts, long-context premiums, regional uplifts, tool charges, gateway
markups, or negotiated pricing. In particular, Claude Haiku 5.5's listed base rate
applies through 100,000 prompt tokens; larger prompts cost $0.50/$2.50 per million
input/output tokens. Aggregated run tokens cannot reliably determine per-request
pricing tiers. Rates here must not be presented as exact billing.

Agents returns zero for unknown prices (unknown, not free). App Studio retains
its fixed $5/$25 per-million-token budgeting fallback for unknown models; it is
not a guaranteed upper bound. App Studio intentionally prices cached prompt
tokens at the full input rate when enforcing spend caps. Existing recorded costs
are not retroactively repriced. Invoice reconciliation needs per-call model,
endpoint, tier, cache breakdown, pricing version, and provider billing data.
