# Link

## Purpose

Take a user to a named destination while preserving normal browser navigation.

## Use when

The outcome is a route, a resource detail, or an external URL. A link can appear inline, as a resource name in a table, or with button styling when navigation is a prominent next step.

## Avoid when

The control performs an operation, submits a form, opens a menu, or changes local state without a destination. Use a button for those actions. A resource that is unavailable should not expose a misleading link.

## Anatomy and variants

Use an anchor with a real `href` and a concise destination label. Table identities can use `.k-table-resource-link`; a prominent navigation link can use the `.k-btn` recipes. `ResourceBackLink` owns the specialized detail-page return treatment. These are existing recipes, not a single new shared link component; other inline links retain their local context styling.

## Behavior

Host-route workspace links use the shared `portalHref` helper so the current URL supplies the scope; do not infer another workspace from cross-tab storage. Agents hash-route links use their route builder and retain the current document path and scope. An in-app handler may intercept an unmodified primary click. Preserve modified clicks, middle-click, context menus, and the real destination for normal browser navigation. Some existing product rows still use buttons for navigation and require migration; the Edge, Code, Infrastructure, and App Studio collection links are scoped examples, not proof of product-wide adoption.

## Content

Name the destination or resource, not the icon. For a link that opens a new tab, communicate that behavior in its accessible name or accompanying text. Icon-only links need an accessible name. External-link icons supplement rather than replace a label.

## Layout and responsive behavior

Keep inline links distinguishable within their surrounding content; table identity links should not resemble miniature filled buttons. Preserve a readable label at narrow widths, and provide the shared coarse-pointer target size when the link is an action-sized control. Native inline text links follow text flow.

## Accessibility

Use a native anchor for navigation and retain its visible keyboard focus indicator. Do not rely on color alone to distinguish a link within prose. Disabled navigation needs a meaningful explanation and must not misrepresent an operable destination. Modified-click and screen-reader behavior should be checked alongside visual styling; product-wide review is pending.

## Code and evidence

The [shared CSS](../../../provider-sdk/portalkit/railgrid-ui.css) defines table and button recipes, and [navigation helpers](../../../provider-sdk/portalkit/navigation.ts) build scoped host URLs. [Edge Services](../../../providers/edges/portal/src/Services.vue) uses a real resource href with an in-app click handler. The [Edges collection](../../../providers/edges/portal/src/EdgeCollection.vue) links each server, cluster, and Mac to its detail route. [Code repositories](../../../providers/code/portal/src/views/RepositoriesView.vue) applies the same distinction to repository identities and suppresses navigation while deletion is in progress. The [design-book specimen](http://127.0.0.1:5197/?entry=design.components.link) compares the recipes; the [Edge Services fixture](http://127.0.0.1:5199/product.html) mounts the product list with sample data and no hub. The populated [Services](http://127.0.0.1:5199/product.html) and [Workloads](http://127.0.0.1:5199/product.html?view=workloads) fixtures also show header creation links; mounted tests cover their scoped destinations and modified clicks, and their mobile targets measured 44px high. The [Edges collection fixture](http://127.0.0.1:5199/edges.html?scenario=links) shows three sample edge kinds; at 390px with touch emulation, their links measured at least 44px high. A mounted test checks scoped, encoded routes and modified clicks. The [Infrastructure instances fixture](http://127.0.0.1:5201/instances.html?scenario=links) contrasts a ready link with a non-navigable deleting instance. At 390px with touch emulation, the ready link measured 44px high; a mounted test checks its scoped route and modified-click behavior. The [Infrastructure catalog fixture](http://127.0.0.1:5201/catalog.html) compares template links in cards and rows; both use 44px-or-larger targets at 390px with touch emulation. Scoped destinations and modified clicks have mounted test coverage. The catalog’s My instances link and the instance list’s Browse templates link also preserve scoped destinations and modified clicks; both measured 44px high in those mobile fixtures. The [Agents webhooks fixture](http://127.0.0.1:5198/?provider=agents&scenario=webhook&route=%23%2Fwebhooks) shows a hash-route link. At 390px with touch emulation, it measured 44px high; an ordinary click opened the sample detail, and mounted tests checked modified clicks on webhook and trigger links. The [Agents connections fixture](http://127.0.0.1:5198/?provider=agents&scenario=connection-states&route=%23%2Fconnections) shows connection identity and creation links; an ordinary click opened the sample edit screen, and touch targets measured 44px high at 390px. Mounted tests cover encoded destinations and modified clicks. The fixture does not verify live host navigation. The [trigger editor fixture](http://127.0.0.1:5198/?provider=agents&scenario=automation-review&route=%23%2Fagents%2Fresearch-assistant%2Ftriggers%2Fon-release%2Fedit) shows related webhook links; they measure at least 44px high at 390px with touch emulation. The editor removes their destinations and tab stops while saving, with mounted coverage of the busy and modified-click states. The [Agents collection fixture](http://127.0.0.1:5198/?provider=agents&scenario=layout&route=%23%2Fagents) shows directly focusable list links; an ordinary click opened the sample chat, and links measured 44px high at 390px with touch emulation. The [App Studio projects fixture](http://127.0.0.1:5198/?provider=app&scenario=project-links&route=%2F) compares gallery and list project links with a deleting project, which has no destination.
